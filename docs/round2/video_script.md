## Important Before Recording

The current running dashboard is still the aquaculture sample monitor. The repository contains purifier-oriented software scaffolds and simulations, but the available evidence does not verify a physical purifier prototype, calibrated live sensors, ED recovery, or tested safety interlocks. Do not present simulated values as sensor measurements or claim prototype functions that are not physically demonstrated. Replace the bracketed cues only with real, dated footage and measured values. If a physical subsystem is not ready, state that it is pending.

## Capture Checklist

- Keep the final edit at or below 90 seconds and 50 MB.
- Show team details, the problem, progress, and a real core-function demonstration.
- Put the prototype in clear view; keep shots stable and well lit.
- Display units, reference instruments, and test date for any measurement.
- Label every simulated screen or value as simulation.
- Show the safety mechanism itself and the test, not only a slide describing it.
- Ensure every number in the narration matches the progress report and the dated test record.
