1. Problem and Proposed Solution

Single-parameter TDS monitoring can miss turbidity and organic-load changes. Conventional RO also sends mineral-bearing reject water to drain, while fixed filter schedules can replace cartridges too early or too late. AquaSense Pro proposes pH, TDS, turbidity, and UV254 sensing around an RO purifier; ReGen-X proposes electrodialysis-based calcium/magnesium recovery and controlled redosing. Pressure, flow, and operating history are intended to support filter-life estimates. These are design goals, not validated performance results.

Risks, Safety & Next Steps

4. Changes Since the Abstract and Open Gaps

The project direction remains AquaSense Pro & ReGen-X. The repository now includes a purifier-specific dashboard with a live USB serial reader matched to the included sketch, alongside the original aquaculture workflow. The live path is implemented but was not tested with an attached board. No performance claims are supported by physical test data in the repository.

  • Targets still requiring measured evidence include combined TDS/turbidity/UV254 sensing, reduced mineral-bearing reject, filter-life prediction, and snap-lock replacement time.
  • The abstract’s stated RUL target (>92%) is not an achieved result. Report it only after chronological validation on a defined held-out dataset, with MAE, RMSE, and R².
  • The abstract schedules final prototype readiness for 8 November, after the Round 2 deadline of 4 November. Re-plan to submit only evidence available by the deadline.
