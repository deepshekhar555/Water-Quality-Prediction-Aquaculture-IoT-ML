# Water-Quality-Prediction-in-Aquaculture-Using-Machine-Learning-Internet-Of-things
Developed a IoT-based water monitoring system integrates sensors to collect real-time data on water quality parameters such as temperature, pH levels, dissolved oxygen, turbidity crucial for aquatic life.
implemented a two-step approach: manual data collection using IoT sensors followed by predicting water quality using a machine learning algorithm for enhanced environmental management.
